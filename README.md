SmartGalaxy - Mobile Shop E-Commerce Website
Welcome to the SmartGalaxy repository! 🎉
SmartGalaxy is a dynamic, full-featured mobile shop e-commerce website built with PHP and MySQL. This project provides a complete solution for online mobile stores, offering a smooth and secure shopping experience for customers while allowing shop owners to easily manage their products, orders, and users.


Key Features 🚀
🌟 User Authentication
Secure Login and Signup functionality to protect user data and ensure a smooth experience.

🛒 Product Cart
Customers can add products to the cart, modify quantities, and proceed to checkout.

📜 Order History
View past orders with detailed information, including product details and order status.

📱 Product Listings
Clean, mobile-responsive product pages that include product details, prices, images, and more.

💻 Mobile-Responsive Design
A sleek, mobile-friendly design ensures an excellent experience across all devices (smartphones, tablets, and desktops).

👨‍💻 Admin Panel
An intuitive admin dashboard for managing products, orders, and user accounts with ease.

⚙ Robust Backend
Powered by PHP and MySQL, ensuring secure transactions and efficient data handling.
